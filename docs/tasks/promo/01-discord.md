# Discord opencode — черновик поста

Куда: официальный Discord opencode (invite на https://opencode.ai/docs),
канал типа #show-your-work / #plugins / #community — уточнить по факту.

Формат: короткий текст + GIF. Не делать длинный пост — в чатах читают бегло.

---

**Текст:**

> **idea-inbox** — a sidebar backlog for stray thoughts.
>
> You're 20 minutes into a refactor, an unrelated thought shows up. Don't
> derail the agent: `leader+z` parks it, `leader+i` dispatches it to an agent
> as a mission when you're ready, and you watch it move
> `○ parked → ◐ running → ● done`.
>
> Agents can manage the backlog themselves via tools.
>
> Install (opencode v2 ≥ 2.0.20): `"plugins": ["opencode-idea-inbox"]`
> npm: https://www.npmjs.com/package/opencode-idea-inbox
> GIF: https://raw.githubusercontent.com/apilot/opencode-idea-inbox/master/assets/demo.gif
