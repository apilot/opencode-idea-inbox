**Subject:** Plugin suggestion for your Best OpenCode Plugins roundup — idea-inbox

Hi!

I maintain **opencode-idea-inbox** (v0.6.1), an npm plugin for opencode v2
that adds a sidebar idea backlog to the TUI:

- `leader+z` parks a stray thought without interrupting the running agent
- `leader+i` dispatches it to an agent as a mission; status moves
  `○ parked → ◐ running → ● done` in the sidebar
- agents manage the backlog themselves via tools

It fits the "improve flow state coding" theme of your roundup: the whole point
is never context-switching away from the current task.

- npm: https://www.npmjs.com/package/opencode-idea-inbox
- GitHub: https://github.com/apilot/opencode-idea-inbox
- Demo GIF: https://raw.githubusercontent.com/apilot/opencode-idea-inbox/master/assets/demo.gif

Would it be a fit for the list? Happy to provide anything you need.

Thanks!
